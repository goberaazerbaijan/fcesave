Tam funksional Cambridge FCE Reading & Use of English imtahan hazırlıq platforması.

- 🔐 İstifadəçi qeydiyyatı və girişi
- 📚 7 Partlıq tam FCE imtahanı (Part 1-7)
- 📝 Hər part üçün xüsusi interfeys (Multiple Choice, Open Cloze, Word Formation, Key Word Transformation, Reading, Gapped Text, Multiple Matching)
- 🛠️ Güclü Admin Paneli (İstifadəçilər, İmtahanlar, Balların təyini, Şagird nəticələri)
- 📜 Avtomatik Karnet (Çap edilə bilən nəticə vərəqi)

## 🚀 Necə İşə Salmaq Olar?

### Lokal Kompüterdə
1. Bu 5 faylı (`index.html`, `style.css`, `app.js`, `README.md`, `.gitignore`) eyni qovluqda yaradın.
2. `index.html` faylını istənilən brauzerdə (Chrome, Firefox, Edge) açın.

### GitHub Pages ilə Yayımlamaq (Pulsuz)
1. GitHub-da yeni **Public** repository yaradın (məsələn: `cambridge-fce`).
2. Bu 5 faylı repository-ə yükləyin (Upload files).
3. Repository **Settings** → **Pages** bölməsinə daxil olun.
4. **Source** olaraq `main` branch və `/ (root)` qovluğunu seçin, **Save** edin.
5. 1-2 dəqiqədən sonra saytınız `https://<istifadəci-adiniz>.github.io/cambridge-fce/` ünvanında canlı olacaq.
